# Personnel File Test
## Upload and Edit the documents
 - This test first uploads all the documents by filling the mandatory fields and then clicks on the "Actions" button and then "Edit" button. Now, it validates the fields given before and fills the fields which are not mandatory and clicks on the update button on the popup.

 - The above test will be done for all 27 documents listed below.

----------------------------------------------------------------------

## Request and Upload Documents 

Requesting documents allows you to gather necessary files upload them efficiently.


### <u>Request and Upload Individual</u>

   1. **Go to the Documents Section**:
      - Navigate to the Personnel File.
      - open the selected **Documents** tab.
      - Click on **Initiate** and select **Request Document** for the respective document type.

   1. **Receive and Upload**:
      - Upload the received document in mail and validate the data.

   1. **Perform Actions for all uploaded documents**:
      - View and validate document.
      - Download document
      - Edit document: validate previous data and again validates updated data
      - Share document: open mail and check whether the shared documet received or not.
      - Remove document


<hr style="width: 50%; margin-right: 50%;">


### <u>Request and Upload Multiple</u>

   1. **Request Multiple**:
      - Navigate to the Personnel File.
      - Click on **Request Multiple**, select Multiple documents and send request.
  
   1. **Cancel Requests**:
      - validate requested documents list, count and cancel all the documents.

   1. **Receive and Upload**:
      - Again click on Request Multiple and Send Request.
      - Upload the received documents in mail and validate the uploaded data.

   1. **Perform Actions for all uploaded documents**:
      - View and validate document.
      - Download document
      - Edit document: validate previous data and again validates updated data
      - Share document: open mail and check whether the shared documet received or not.
      - Remove document

 The above tests will be done for all 27 documents listed below.
