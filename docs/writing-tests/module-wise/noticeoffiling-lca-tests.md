# Notice of Filing LCA Documentation

## Overview

**Test Name**: `LCANoticeOfFiling_Test`

#### Description
This test case outlines the workflow for filing a LCA notice. It includes onboarding the employee, managing LCA numbers, Adding LCA Notice, Validating data, and Performing necessary actions related to the notice filing process.

#### Steps


   1. **Onboard Employee**
      - Onboard the Employee.
 
   1. **Check LCA Number Availability**
      - Navigate to the LCA List.
      - Search the LCA number whether it is available or not in the system.
      - If it is already available, create an another LCA number for further processing.

   1. **Add Project**
      - Add Project for the Onboarded Employee from their profile.  
      
   1. **Add LCA Notice**
      - Navigate to Projects.
      - Select 'Add LCA Notice' using the Actions button of the project 
      - Selects one of the following options:
        - **Generate Notice of filing LCA**
        - **Upload Notice of Filing LCA**
      - If "Generate" is selected,it selects anyone from the option listed below:
        - **Bargaining Representative**
        - **Electronic**
        - **Physical**
        - **Electronic + Physical**
      - Fill details and Preview or Upload.

   1. **Validate Data**
      - Validate Preview (if "Generate" flow is selected)
      - Validate Notice details in the Notice of Filing LCA Tab.

   1. **Perform Actions in Notice of Filing LCA Tab**
      - Perform Actions for Notice in Notice of Filing LCA Tab
      - Actions include View Notice, Share Notice, Shared History and Download Notice.

   1. **Update Notice**
      - Select 'Update Notice' using the Actions button for the project in Projects.
      - Modify Notice details as needed.
      - Validate that updated details in Notice of Filing LCA Tab.

   1. **Perform Actions in Projects**
      - Perform Actions for the project in Projects.
      - Actions include View Notice, Share Notice, Shared History and Download Notice.

   1. **Link LCA with Project**
      - select 'Link LCA' using the Actions button for the project.
      - Validate the details in the Projects row

   1. **Delete Notice**
      - Delete the Notice using the Actions button of the project in the Notice of Filing LCA Tab .

   1. **Delete LCA**
      - Remove the LCA record if no longer required.
   
   1. **Delete Project**
      - Delete the linked project if it is no longer associated with any LCA.
   
   1. **Delete Employee**
      - Remove the employee record after all associated data has been handled.
